Privacy Policy

Last updated: 2026-09-14 · Effective date: 2026-09-14

Short version: Primo Reader is fully offline. We do not collect, transmit, sell, share, or otherwise process any personal data. The application makes no outbound network requests in normal use. There is no server, no account, no analytics SDK, no crash reporter, no advertising SDK, no third-party tracker of any kind.

1. Information we do NOT collect

The Application does not collect:

  • Personal identifiers (name, email, phone number, postal address)
  • Account credentials
  • Device identifiers for tracking purposes
  • Location data (GPS, IP-based geolocation, cell/wifi triangulation)
  • Usage analytics or telemetry
  • Crash reports or diagnostic data
  • Ad identifiers (GAID/IDFA) or fingerprinting signals
  • Book metadata, reading progress, bookmarks, or any content you load

2. Information stored locally on your device

The following information is stored only on your device, in a SQLite database file inside the application's sandboxed storage, and is never transmitted to us or any third party:

  • Books you import (file paths only; the application reads file contents from your file system but does not exfiltrate them)
  • Reading position, bookmarks, and per-book settings
  • Application preferences (font size, theme, TTS voice, default speed, …)

You can wipe this data at any time via the application's Settings screen, or by uninstalling the application (which also deletes the database file).

3. Network activity

In normal use the Application makes no outbound network requests of any kind.

If you grant the Application permission to read books from cloud storage (e.g. Google Drive, iCloud Drive) in the future, your file picker will communicate with the corresponding operating-system service; that communication is governed by Google/Apple's privacy policies, not ours.

4. Children

The Application is rated Everyone / 4+ and does not target minors. We do not knowingly collect data from children under 13 (COPPA), under 16 (GDPR-K), or any other age threshold. Because we collect no data at all, this is trivially satisfied.

6. International transfers

We make no international transfers of personal data because we have no personal data.

7. Changes to this policy

If we ever add a feature that requires any data to leave your device — for example, optional cloud sync, crash reporting, or analytics — we will:

  1. Update this policy with a new effective date and a diff summary.
  2. Surface a re-consent prompt on the next application launch.
  3. Provide an opt-out path that retains current offline behavior.
