Frequently Asked Questions

How do I add my books?

Tap + in the library and pick an .epub or .txt file with the system file picker. The file is copied into the app's private storage; the original stays untouched.

The read-aloud voice sounds robotic. Can I improve it?

Primo Reader uses your device's built-in text-to-speech engine. You can get much better voices for free from your system settings — no purchase needed:

  • Android: Settings → System → Text-to-speech → Google Text-to-Speech → install high-quality languages (download the enhanced/neural variants when offered).
  • iOS: Settings → Accessibility → Spoken Content → Voices → choose a voice marked "Enhanced" or "Premium" and download it.

Then pick the new voice inside Primo Reader's playback settings. Per-book voice and speed are remembered.

Read-aloud stops when I lock the screen / switch apps.

This is the #1 issue on Android, and it's a settings problem, not an app bug. Many phone brands add their own aggressive battery managers on top of Android. These ignore the standard "unrestricted battery" setting, so you may need to flip a second, brand-specific switch. Follow the steps in order:

  1. Standard Android setting (always do this first): Settings → Apps → Primo Reader → Battery → Unrestricted (a.k.a. "not optimized").
  2. Your phone brand's own background-power switch — the exact name varies by brand, look for "background power management", "background power drain", "battery saver policy" or "auto-launch" inside the battery or app-management settings:
    • Phones with a “后台耗电管理 / Background power management” list under Settings → Battery: set Primo Reader to allow background activity.
    • Phones with a “省电策略 / Battery saver policy” option on each app's page: choose No restrictions / Unrestricted.
    • Phones with an “auto-launch / launch manager” on each app's page: disable "manage automatically" and allow all three toggles.
  3. Notification & lock-screen controls: if playback works in the background but you don't see the media card on the lock screen, check Settings → Notifications → Primo Reader → allowed, and the system's "lock screen notifications" style setting (some brands default to hiding them).

The in-app prompt links to the battery settings; the brand-specific switch must be flipped manually — no app can change it for you (Android security model).

I don't see the media controls on the lock screen / notification shade.

Check, in order: (1) notifications for Primo Reader are enabled; (2) your phone's "lock screen notifications" is set to show all notifications — several brands default to hiding them; (3) start playback once with the app in the foreground — controls appear on the first play and persist while the app is alive. If they disappear after pausing/resuming, that was a bug fixed in recent versions: update the app.

Why is there no cloud sync?

By design. Sync requires accounts and servers, which means your reading data leaves your device. Primo Reader is built so that nothing ever does. If you switch devices, exporting and re-importing your library is on the roadmap.

Why can't the app find books on its own?

Primo Reader does not host, recommend, or search for any content — it is a reader only. You supply the files. This keeps the app legal, simple, and free of any catalogue that could disappear.

A specific EPUB looks broken (missing images / wrong order).

EPUB files vary wildly in quality. Please email the file (or a similar sample) to the address above — compatibility fixes are the top development priority.

How do I delete all my data?

Settings → Clear library data, or simply uninstall the app. Both remove the local database permanently. There is no server copy — deletion is immediate and total.

Is it really free? What's the catch?

The core app is free. A one-time purchase may later unlock optional extras (themes, import batches) — it will never be a subscription, and the reading core stays functional regardless.
